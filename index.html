Stage 1 - Single tool use. The agent picks one tool, calls it once, observes the result, and answers. The loop always runs exactly twice.
Stage 2 - ReAct loop. The agent reasons and acts in multiple rounds, chaining tools in sequence until the goal is complete. Watch the iteration counter climb.
Stage 3 - Memory. The agent remembers facts across sessions via localStorage. Saved facts inject into the next conversation automatically.
Stage 4 - Multi-agent. One orchestrator delegates to specialist agents running in parallel. Each specialist handles one domain. Results are synthesised into a final answer.
